STAR FOX ENHANCED - STEAM FRAME DEVELOPMENT BUILD

This is a native Linux ARM64 OpenXR build. It requires the Steam Frame system
Vulkan driver and an active OpenXR runtime. The package does not include a
cartridge, generated Starfox-Assets.BIN, soundtrack pack, save data, or Vulkan
driver files.

Prepare Starfox-Assets.BIN from your own supported, unmodified retail ROM with
the matching starfox_asset_builder from a desktop build. Copy the generated
BIN to:

  $XDG_DATA_HOME/StarFoxEnhanced/Starfox-Assets.BIN

If XDG_DATA_HOME is unset or relative, the default is:

  $HOME/.local/share/StarFoxEnhanced/Starfox-Assets.BIN

The same directory stores saves, preferences, and the shader cache. Package
files can remain read-only. Run LAUNCH-STEAM-FRAME.sh from any working
directory. To choose another asset bundle, data directory, or optional MSU-1
pack, pass --bundle PATH, --data-dir PATH, or --msu PATH. Run
starfox_steamframe --help for startup options.

Native Frame controls: A brake, B bomb, X shoot, Y boost; bumpers roll.
Menu is source Start/pause; View is source Select. Cartridge control type and
face-button swap options still apply to gameplay.

Menu + View opens host runtime settings. Use the stick/D-pad to move and A or
Menu to confirm. OPTIONS > VR PRESENTATION selects the existing camera
(default) or pilot/cockpit view, world scale, head translation strength,
cockpit XYZ origin calibration, and RECENTER. Head translation preserves IPD.
Use EXIT in the host menu, then YES / EXIT to quit; NO / BACK returns.

No ROM, generated BIN, private music, saves, or keys are included or should be
redistributed with this package. Physical headset startup, tracking, controller
input, comfort, and sustained performance still require Steam Frame testing.
